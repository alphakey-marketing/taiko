# UI Wireframe — 戰國立志錄 MVP

## Screen Flow

```
[Title Screen]
      ↓
[Character Creation] — choose name + background (武士見習 / 商人學徒)
      ↓
[Game Screen] ←→ [Character Panel (overlay)]
                ↕
          [Event Modal (overlay)]
```

---
